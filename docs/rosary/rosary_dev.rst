===============================
Rosary: developer reference
===============================

``rosary`` is a Sphinx directive. All twenty mysteries, their icons, their
scripture references and the opening and closing prayers are built in, so a
page needs only one line.


Installing
==========

#. Copy the ``rosary`` folder into ``docs/_ext``.
#. In ``conf.py``, make sure ``_ext`` is on the path and add the extension:

   .. code-block:: python

       sys.path.append(os.path.abspath("./_ext"))

       extensions = [
           # ...
           "rosary",
       ]

The extension adds its own ``rosary.css`` and ``rosary.js``, and copies the
picture folders and the Home Screen icon into the built site. Nothing else
is needed in ``conf.py``: the starting choices are built in (see
*Site-wide starting choices*).


Folder contents
===============

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - File
     - Purpose
   * - ``rosary.py``
     - The directive. Writes the sets, mysteries and references as HTML.
   * - ``rosary_data.py``
     - The 20 mysteries: title, fruit, days and ten ``(reference, caption)``
       pairs each, plus the words of the prayers.
   * - ``rosary_meditations.py``
     - For each of the 20 mysteries, a short meditation and closing prayer
       (``MEDITATIONS``) and a Montfort-style offering of the decade
       (``OFFERINGS``), shown when **Under the beads** is set to *A
       meditation* or *A Montfort-style offering*, and a modern reflection
       with a question (``MODERN``) for *A modern reflection*. Original
       text; edit freely (a clean build is needed afterwards). It also holds
       ``VIRTUES`` (a meditation on each mystery's fruit) and ``INTENTIONS``
       (an intention, reflection and prayer for each decade).
   * - ``rosary_classic.py``
     - The classic meditations for the 15 traditional mysteries (``CLASSIC``:
       title, paragraphs, invocation), from *The Rosary* (San Francisco,
       1915), public domain, for *A classic meditation (1915)*. The Luminous
       Mysteries show the meditation instead.
   * - ``rosary_scripture.py``
     - The verse text of all 200 references (CPDV). Generated by
       ``make_scripture.py``.
   * - ``make_scripture.py``
     - Rebuilds ``rosary_scripture.py`` from the CPDV text file. Not used by
       Sphinx.
   * - ``rosary_icons.py``
     - The 20 icons and the opening and closing icons, drawn as inline SVG,
       plus the stained-glass background.
   * - ``_static/rosary.css``
     - Picture styles, layouts, full screen, the Options panel, set colours,
       dark mode and print styles.
   * - ``_static/rosary.js``
     - Tabs, today's set, the mystery picker, the decade of beads, the
       opening and closing prayers, the Options panel, full screen and
       read-aloud.
   * - ``_static/rosary-touch-icon.png``, ``rosary-icon-512.png``,
       ``rosary-manifest.json``
     - The Home Screen icon and web app manifest.


Usage
=====

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Directive
     - Shows
   * - ``.. rosary::``
     - All four sets, with tabs, opening on today's set
   * - ``.. rosary:: today``
     - Only the set for today's day of the week
   * - ``.. rosary:: joyful``
     - One set (``joyful``, ``luminous``, ``sorrowful`` or ``glorious``)
   * - ``.. rosary:: glorious`` with ``:mystery: 3``
     - One mystery (here, the Descent of the Holy Spirit), without the
       opening and closing prayers

The page reads and prints without JavaScript. ``today`` is worked out in the
reader's browser, so it is correct on a static site.


Options
=======

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Option
     - Effect
   * - ``:title:``
     - Heading above the block.
   * - ``:mystery:``
     - ``1`` to ``5``. Show only that mystery of the named set.
   * - ``:open:``
     - With all four sets, the set to open first instead of today's set.
   * - ``:bible-version:``
     - BibleGateway version code for the reference links (default ``NRSVCE``;
       e.g. ``RSVCE``, ``DRA``, ``NABRE``). ``none`` gives plain-text
       references with no links.
   * - ``:prayers:``
     - Show the words of the prayers on each bead from the start.
   * - ``:no-beads:``
     - Leave out the beads, buttons and opening and closing prayers.
       Reference lists only.
   * - ``:no-captions:``
     - References only, without the one-line summary of each passage.
   * - ``:no-scripture:``
     - Leave out the verse text under each reference (a shorter page to print).
   * - ``:no-audio:``
     - Leave out the **Reading aloud** options and the **🔊 Listen** buttons.
   * - ``:icons:``
     - Picture style to start with: ``classic``, ``stained``, ``gold``,
       ``photo`` (Masterpieces), ``photo-sg`` (Stained glass
       windows), ``photo-cubism`` (Cubism), ``photo-modaus`` (Modern
       Australian) or ``photo-trad`` (Renaissance style); ``photo-<key>`` for any other
       picture folder.
   * - ``:images:``
     - Folder of pictures for this rosary instead of the site's
       ``rosary_images`` folder (see below). Starts on them unless
       ``:icons:`` says otherwise. ``none`` turns pictures off.
   * - ``:no-picker:``
     - Leave out the **Pictures**, **Mystery picker**, **Layout**,
       **Scripture verses** and **Opening & closing** menus, so the page
       always uses the directive's (or the site's) choices for these.
   * - ``:extra-prayers:``
     - The opening and closing prayers: ``off``, ``on`` (Sign of the Cross,
       Apostles' Creed, Our Father, three Hail Marys, Glory Be; Hail Holy
       Queen, versicle, closing prayer, Sign of the Cross) or ``full`` (also
       the Prayer to St Michael and the Memorare).
   * - ``:fatima:``
     - ``yes`` or ``no``: the Fatima prayer (O my Jesus) after the Glory Be
       at the end of each decade.
   * - ``:hide-title:``
     - Hide the page's main heading. It still names the page in the menu
       and the browser tab.
   * - ``:nav-icons:``
     - Picture style for the mystery picker's small pictures: ``same`` (as
       the main pictures, the starting choice), ``classic``, ``stained``, ``gold``, ``photo`` or
       ``photo-sg``.
   * - ``:layout:``
     - ``auto``: picks ``iphone`` below 700 pixels wide, ``ipad`` up to 1200
       and ``desktop`` above, in the reader's browser. ``desktop``: the
       picture as large as the screen allows on the left, with the details
       in a column on the right (on wide screens the rosary widens into empty
       space right of the page). ``ipad``: a tablet-sized picture on the
       left, with the title, beads and the ten steps beside it. ``iphone``:
       the picture on top, then smaller beads and buttons and the details.
       The old names still work: ``phone`` and ``large`` give ``ipad``,
       ``side`` gives ``desktop`` and ``compact`` gives ``iphone``.
   * - ``:under:``
     - What is shown under the beads: ``none`` (the starting choice),
       ``all`` (every alternative to the steps), or any of ``steps``,
       ``meditation``, ``virtue``, ``intention``, ``offering``, ``classic``
       and ``modern``, separated by commas, e.g. ``:under: steps, meditation``.
       They are the ten steps, and the mystery's meditation, meditation on its
       virtue, intention, Montfort-style offering, classic (1915) meditation
       and modern reflection, shown in that order.
   * - ``:virtues:``
     - ``yes`` or ``no``: show each mystery's virtue (its fruit) under its
       name in the mystery picker. Readers can change it with the **Show
       virtues** checkbox.
   * - ``:pictures:``
     - ``yes`` or ``no``: show the main picture of each mystery. Readers can
       change it with the **Show pictures** checkbox.
   * - ``:verses:``
     - Where the scripture is shown: ``all`` (under each step), ``current``
       (only the step being prayed, in the panel at the top) or ``none``.
   * - ``:read:``
     - What the **🔊 Listen** buttons read on each Hail Mary bead:
       ``step`` (the summary), ``both`` or ``scripture``.

Options that match a menu in the Options panel (``:icons:``, ``:nav-icons:``,
``:layout:``, ``:pictures:``, ``:under:``, ``:verses:``, ``:read:``, ``:extra-prayers:``,
``:fatima:``)
set the page's starting choice; when one is left out, the site's starting
choice is used (see *Site-wide starting choices*). A reader's own choice from
the Options panel takes over on later visits.

Scripture text
==============

The verses are from the **Catholic Public Domain Version** (CPDV), which is in
the public domain, so it can be printed and shared freely. Copyrighted
translations (NRSV, NABRE, RSV-CE, Jerusalem Bible) can only be linked to.

References in ``rosary_data.py`` use NRSV numbering, to match the BibleGateway
links. The CPDV follows the Vulgate, so ``make_scripture.py`` maps these
passages to the CPDV verses with the same text, and the page shows the CPDV
number in brackets:

.. list-table::
   :header-rows: 1
   :widths: 50 50

   * - NRSV
     - CPDV
   * - Psalm 16:10
     - Psalm 15:10
   * - Psalm 45:9
     - Psalm 44:10
   * - Psalm 132:8
     - Psalm 131:8
   * - Judith 13:18
     - Judith 13:23
   * - Judith 15:9
     - Judith 15:10
   * - Song of Solomon 2:10-11
     - Song of Solomon 2:12-13
   * - John 6:51
     - John 6:51-52
   * - John 6:54-56
     - John 6:55-57


Read-aloud
==========

Read-aloud uses the browser's Web Speech API, so there are no audio files and
nothing is sent to a server. ``rosary.js``:

* lists the English voices, choosing en-AU first, then en-GB, preferring
  *Natural*, *Online* and *Google* voices, and stores the reader's choice of
  voice and speed in the browser (``localStorage``);
* reads each bead in short sentence-sized pieces, because some browsers cut
  off long speech;
* on each Hail Mary bead reads the step, the passage or both (``:read:``),
  plus the prayer when **Show the prayers** is ticked;
* on the opening and closing beads reads the prayer, announced by name and
  intention first when **Read prayer names** is ticked.

If the browser has no speech support, the audio controls are not shown.


Pictures
========

The 20 icons are drawn once, in ``rosary_icons.py``, using colour classes
such as ``ri-fill`` and ``ri-gold``. Each picture style in ``rosary.css``
recolours those classes, chosen by the block's ``data-icons`` attribute:

* **stained** shows a rose-window background (``ri-glass-bg``, hidden in the
  other styles), thick dark outlines as leading, jewel colours, an arched
  frame and a glass shine;
* **gold** puts the drawing on a gold-leaf gradient with brown linework.

A new style needs only CSS: copy one of the blocks under *picture styles* in
``rosary.css`` and add its name to ``STYLES`` in ``rosary.js`` and
``ICON_STYLES`` in ``rosary.py``.

Masterpieces and your own pictures
----------------------------------

Every rosary offers the pictures in the site's picture folder as
**Masterpieces** in the **Pictures** menu. The folder is set in
``conf.py`` (this is the default):

.. code-block:: python

    rosary_images = "/_static/rosary-images"   # "" for no pictures

It holds 20 public-domain paintings (see
:doc:`masterpieces </rosary/rosary_artworks>`).

A second folder, ``/_static/rosary-images-sg``, is offered as **Stained
glass windows**, for photographs of stained-glass windows. It works the same
way: pictures named ``joyful-1.jpg`` ... ``glorious-5.jpg``, an optional
``credits.txt`` and an optional ``full`` folder. Its pictures are
perspective-corrected photographs saved as ``.webp``. A third folder,
``/_static/rosary-images-cubism``, is offered as **Cubism**, a fourth,
``/_static/rosary-images-mod-aus``, as **Modern Australian**, and a fifth,
``/_static/rosary-images-trad``, as **Renaissance style**, in the same way. Each folder becomes its own
entry in the **Pictures** menu, in this order: Stained glass windows, Cubism,
Renaissance style, Modern Australian, Masterpieces, then the drawn styles (the
**Mystery picker** menu uses the same order under **Same as pictures**); a folder that is missing or empty is left
out, and a mystery without a picture in the chosen folder uses its drawn
icon. In the iPad layout, wide (landscape) pictures are framed to their own
shape; tall ones keep the phone-shaped frame.

More folders can be listed in ``conf.py``, each with a short key and its
menu label, in the order the menu should list them (this replaces the five
defaults):

.. code-block:: python

    rosary_image_sets = [
        ("sg", "Stained glass windows", "/_static/rosary-images-sg"),
        ("cubism", "Cubism", "/_static/rosary-images-cubism"),
        ("trad", "Renaissance style", "/_static/rosary-images-trad"),
        ("modaus", "Modern Australian", "/_static/rosary-images-mod-aus"),
        ("photo", "Masterpieces", "/_static/rosary-images"),
        ("icons", "Eastern icons", "/_static/rosary-images_icons"),
    ]

A page can open on one with ``:icons: photo-sg`` (or ``photo-icons``). A ``full`` folder
inside it may hold the uncropped paintings with the same names; clicking a
picture then shows the whole painting with its caption.

To use other pictures:

Put the pictures in one folder, named by set and number:

.. code-block:: text

    joyful-1.png ... joyful-5.png
    luminous-1.png ... luminous-5.png
    sorrowful-1.jpg ...            (.png, .jpg, .jpeg, .webp, .gif or .svg)
    glorious-1.png ... glorious-5.png

then point the directive at the folder. A path starting with ``/`` is from
the ``docs`` folder; otherwise it is from the page's own folder.

.. code-block:: rst

    .. rosary::
        :images: /_static/rosary-images

Any picture that is missing uses the drawn icon. An optional ``credits.txt``
in the folder adds a caption under each mystery's title, one line per
picture:

.. code-block:: text

    joyful-1: Fra Angelico, The Annunciation (c. 1426), Museo del Prado, Madrid
    opening: Masaccio, The Holy Trinity (c. 1427), Santa Maria Novella, Florence

Pictures named ``opening`` and ``closing`` (with any of the same extensions)
are shown for the opening and closing prayers, with ``opening:`` and
``closing:`` lines in ``credits.txt``. Without them, the drawn opening and
closing icons are used.

:doc:`Masterpieces </rosary/rosary_artworks>` lists a public-domain
painting for every mystery, with a ready-made ``credits.txt``. The pictures are copied into
the built site automatically. Square pictures work best: they are cropped to
fill the frame. Use only pictures you have the right to publish, such as your
own photos.


Site-wide starting choices
==========================

Each option above can be set for one page in its directive. The starting
choices for every rosary on the site are built into ``rosary.py``, so
``conf.py`` doesn't need to mention them. To change one, add its line to
``conf.py``; these are the built-in values:

.. code-block:: python

    rosary_default_icons = "photo-sg"        # classic, stained, gold, photo, photo-sg, photo-cubism, photo-modaus, photo-trad
    rosary_default_nav_icons = "same"        # same, classic, stained, gold, photo, photo-sg
    rosary_default_layout = "auto"           # auto, desktop, ipad, iphone
    rosary_default_pictures = True           # False to start with the pictures hidden
    rosary_default_virtues = True            # False to hide the virtues in the mystery picker
    rosary_default_under = "none"            # none, all, or e.g. "steps, meditation" (steps, meditation, virtue, intention, offering, classic, modern)
    rosary_default_verses = "current"        # all, current, none
    rosary_default_read = "step"             # step, both, scripture
    rosary_default_extra_prayers = "on"      # off, on, full
    rosary_default_fatima = True             # O my Jesus after each Glory Be
    rosary_default_read_titles = False       # say each opening/closing prayer's name first

After changing one, do a clean build (``make clean``, then ``make html``).
A picture style whose folder is missing falls back to ``classic``. A
reader's own choices from the **Options** menus are kept in their browser
(``localStorage`` keys starting ``rosary-``) and take over from these.
**Reset to starting choices** in the Options panel removes those keys and
reloads the page.

The opening and closing prayers are ``OPENING`` and ``CLOSING`` in
``rosary_data.py``: one entry per bead, with its label, name, intention and
prayers (keys of ``PRAYERS``). After editing ``rosary_data.py``,
``rosary_icons.py`` or ``rosary_scripture.py``, do a clean build so Sphinx
doesn't reuse its cached pages.


The Options panel
=================

``rosary.js`` builds each menu, then groups them in the panel as three
``fieldset`` cards (*Pictures*, *Prayers*, *Reading aloud*), with the
**Reset to starting choices** and **Done** buttons underneath. A new menu
added to the panel's ``bar`` is put in a final *Other* group unless it is
added to one of the three lists in the grouping code. The cards sit side by
side in a CSS grid (``.rosary-opt-groups``) and stack on a narrow screen.

Each alternative to the steps is a ``.rosary-under-box`` (``.rosary-meditation``,
``.rosary-virtue``, ``.rosary-intention``, ``.rosary-offering``, ``.rosary-classic``,
``.rosary-modern``) written by
``_under_html`` in ``rosary.py``. The block's ``data-under`` lists what is
ticked, e.g. ``"steps meditation"``, or is ``"none"``; CSS shows each listed
one (``[data-under~="meditation"]``) in a fixed order, and ``rosary.js`` reads
the parts marked ``rosary-say`` of each ticked box aloud on the Our Father
bead. The 📖 panel and the Options tick boxes are made by ``underChecks`` and
kept in step through ``setUnder``.

The block keeps the reader's layout choice in ``data-layout-choice``
(``auto``, ``desktop``, ``ipad`` or ``iphone``) and the layout in use in
``data-layout``; with ``auto``, ``rosary.js`` updates ``data-layout`` when
the window is resized. Each layout's styles in ``rosary.css`` are keyed off
``data-layout``, and **Show pictures** sets ``data-pictures="off"``.

Each reader's choices are saved in ``localStorage``: ``rosary-icons``,
``rosary-nav-icons``, ``rosary-layout``, ``rosary-pictures``, ``rosary-virtues``, ``rosary-under``,
``rosary-verses``,
``rosary-extra``, ``rosary-prayers``, ``rosary-fatima``, ``rosary-read``,
``rosary-read-titles``, ``rosary-voice``, ``rosary-rate``,
``rosary-options-open`` and ``rosary-menus-hidden``.


Home Screen app
===============

So the site can be saved to a phone's Home Screen and open full screen, the
extension adds these to the ``<head>`` of every page after the build: the
``apple-mobile-web-app-capable`` and ``mobile-web-app-capable`` tags, an
``apple-touch-icon`` (``_static/rosary-touch-icon.png``) and a web app
manifest (``_static/rosary-manifest.json``). They are added to the built
pages themselves, so they work with any theme. In ``conf.py``:

.. code-block:: python

    rosary_web_app = True            # False to leave the tags out
    rosary_web_app_title = "Rosary"  # name under the icon (default: project)


Changing the references
=======================

#. Edit ``rosary_data.py``. Each mystery has a ``refs`` list of exactly ten
   ``(reference, caption)`` pairs; the module checks this when Sphinx loads it.
#. Download ``CPDV.csv`` from
   https://github.com/scrollmapper/bible_databases (``formats/csv``).
#. Rebuild the verse text. If a new passage is numbered differently in the
   Vulgate, add it to ``OVERRIDE`` in ``make_scripture.py`` first.

   .. code-block:: text

       cd docs\_ext\rosary
       python make_scripture.py CPDV.csv


Colours
=======

Each set has its own colour, set by CSS variables in ``rosary.css``:

.. code-block:: text

    .rosary-set--joyful    { --r-c: #2f6db5; ... }   /* blue */
    .rosary-set--luminous  { --r-c: #c48300; ... }   /* gold */
    .rosary-set--sorrowful { --r-c: #6d2e7a; ... }   /* purple */
    .rosary-set--glorious  { --r-c: #b0282c; ... }   /* red */

The icons take their colours from the same variables.
