===============================
Rosary: developer reference
===============================

``rosary`` is a Sphinx directive. All twenty mysteries, their icons and their
scripture references are built in, so a page needs only one line.


Installing
==========

#. Copy the ``rosary`` folder into ``docs/_ext``.
#. In ``conf.py``, make sure ``_ext`` is on the path and add the extension:

   .. code-block:: python

       sys.path.append(os.path.abspath("./_ext"))

       extensions = [
           # ...
           "rosary",
       ]

The extension adds its own ``rosary.css`` and ``rosary.js``.


Folder contents
===============

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - File
     - Purpose
   * - ``rosary.py``
     - The directive. Writes the sets, mysteries and references as HTML.
   * - ``rosary_data.py``
     - The 20 mysteries: title, fruit, days and ten ``(reference, caption)``
       pairs each, plus the words of the prayers.
   * - ``rosary_scripture.py``
     - The verse text of all 200 references (CPDV). Generated by
       ``make_scripture.py``.
   * - ``make_scripture.py``
     - Rebuilds ``rosary_scripture.py`` from the CPDV text file. Not used by
       Sphinx.
   * - ``rosary_icons.py``
     - The 20 icons, drawn as inline SVG, plus the stained-glass background.
   * - ``_static/rosary.css``
     - Layout, set colours, icon colours, dark mode and print styles.
   * - ``_static/rosary.js``
     - Tabs, today's set, the mystery picker, the decade of beads and
       read-aloud.


Usage
=====

.. list-table::
   :header-rows: 1
   :widths: 40 60

   * - Directive
     - Shows
   * - ``.. rosary::``
     - All four sets, with tabs, opening on today's set
   * - ``.. rosary:: today``
     - Only the set for today's day of the week
   * - ``.. rosary:: joyful``
     - One set (``joyful``, ``luminous``, ``sorrowful`` or ``glorious``)
   * - ``.. rosary:: glorious`` with ``:mystery: 3``
     - One mystery (here, the Descent of the Holy Spirit)

The page reads and prints without JavaScript. ``today`` is worked out in the
reader's browser, so it is correct on a static site.


Options
=======

.. list-table::
   :header-rows: 1
   :widths: 25 75

   * - Option
     - Effect
   * - ``:title:``
     - Heading above the block.
   * - ``:mystery:``
     - ``1`` to ``5``. Show only that mystery of the named set.
   * - ``:open:``
     - With all four sets, the set to open first instead of today's set.
   * - ``:bible-version:``
     - BibleGateway version code for the reference links (default ``NRSVCE``;
       e.g. ``RSVCE``, ``DRA``, ``NABRE``). ``none`` gives plain-text
       references with no links.
   * - ``:prayers:``
     - Show the words of the prayers on each bead from the start.
   * - ``:no-beads:``
     - Leave out the beads and buttons. Reference lists only.
   * - ``:no-captions:``
     - References only, without the one-line summary of each passage.
   * - ``:no-scripture:``
     - Leave out the verse text under each reference (a shorter page to print).
   * - ``:no-audio:``
     - Leave out the voice bar and the **Listen** / **Pray aloud** buttons.
   * - ``:icons:``
     - Picture style to start with: ``classic`` (default), ``stained``,
       ``gold``, ``photo`` (Traditional paintings) or ``photo-sg`` (Stained
       glass windows); ``photo-<key>`` for any other picture folder. A reader's own choice from the
       **Pictures** menu takes over on later visits.
   * - ``:images:``
     - Folder of pictures for this rosary instead of the site's
       ``rosary_images`` folder (see below). Starts on them unless
       ``:icons:`` says otherwise. ``none`` turns pictures off.
   * - ``:no-picker:``
     - Leave out the **Pictures** and **Layout** menus, so the page always uses
       ``:icons:`` and ``:layout:``.
   * - ``:extra-prayers:``
     - The opening and closing prayers: ``off``, ``on`` (Sign of the Cross,
       Apostles' Creed, Our Father, three Hail Marys, Glory Be; Hail Holy
       Queen, versicle, closing prayer, Sign of the Cross) or ``full`` (also
       the Prayer to St Michael and the Memorare). Readers can change it in
       the **Opening & closing** menu.
   * - ``:fatima:``
     - ``yes`` (default) or ``no``: the Fatima prayer (O my Jesus) after the
       Glory Be at the end of each decade. Readers can change it with the
       **Fatima prayer** checkbox.
   * - ``:hide-title:``
     - Hide the page's main heading. It still names the page in the menu
       and the browser tab.
   * - ``:nav-icons:``
     - Picture style for the mystery picker's small pictures: ``same``
       (default, as the main pictures), ``classic``, ``stained``, ``gold``,
       ``photo`` or ``photo-sg``. A reader's own choice from the **Mystery
       picker** menu takes over on later visits.
   * - ``:layout:``
     - ``phone`` (default): a phone-sized picture on the left, with the
       title, beads and the ten steps beside it. ``compact``: a small picture
       beside the title. ``side``: a large picture on the left, about 75% of
       the width (on wide screens the rosary widens into empty space right of
       the page). ``large``: the picture above, up to 75% of the screen
       height. A reader's own choice from the **Layout** menu takes over on
       later visits.
   * - ``:verses:``
     - Scripture under the steps: ``all`` (default), ``current`` (only the
       step being prayed) or ``none``. Readers can change it in the
       **Verses** menu.
   * - ``:read:``
     - What **Listen** and **Pray aloud** read on each Hail Mary bead:
       ``step`` (the summary), ``both`` (default) or ``scripture``. Readers
       can change it in the **Read aloud** menu.

Scripture text
==============

The verses are from the **Catholic Public Domain Version** (CPDV), which is in
the public domain, so it can be printed and shared freely. Copyrighted
translations (NRSV, NABRE, RSV-CE, Jerusalem Bible) can only be linked to.

References in ``rosary_data.py`` use NRSV numbering, to match the BibleGateway
links. The CPDV follows the Vulgate, so ``make_scripture.py`` maps these
passages to the CPDV verses with the same text, and the page shows the CPDV
number in brackets:

.. list-table::
   :header-rows: 1
   :widths: 50 50

   * - NRSV
     - CPDV
   * - Psalm 16:10
     - Psalm 15:10
   * - Psalm 45:9
     - Psalm 44:10
   * - Psalm 132:8
     - Psalm 131:8
   * - Judith 13:18
     - Judith 13:23
   * - Judith 15:9
     - Judith 15:10
   * - Song of Solomon 2:10-11
     - Song of Solomon 2:12-13
   * - John 6:51
     - John 6:51-52
   * - John 6:54-56
     - John 6:55-57


Read-aloud
==========

Read-aloud uses the browser's Web Speech API, so there are no audio files and
nothing is sent to a server. ``rosary.js``:

* lists the English voices, choosing en-AU first, then en-GB, preferring
  *Natural*, *Online* and *Google* voices, and stores the reader's choice of
  voice and speed in the browser (``localStorage``);
* reads each bead in short sentence-sized pieces, because some browsers cut
  off long speech;
* on each bead reads the passage, plus the prayer when **Show the prayers** is
  ticked.

If the browser has no speech support, the audio controls are not shown.


Pictures
========

The 20 icons are drawn once, in ``rosary_icons.py``, using colour classes
such as ``ri-fill`` and ``ri-gold``. Each picture style in ``rosary.css``
recolours those classes, chosen by the block's ``data-icons`` attribute:

* **stained** shows a rose-window background (``ri-glass-bg``, hidden in the
  other styles), thick dark outlines as leading, jewel colours, an arched
  frame and a glass shine;
* **gold** puts the drawing on a gold-leaf gradient with brown linework.

A new style needs only CSS: copy one of the blocks under *picture styles* in
``rosary.css`` and add its name to ``STYLES`` in ``rosary.js`` and
``ICON_STYLES`` in ``rosary.py``.

Traditional paintings and your own pictures
-------------------------------------------

Every rosary offers the pictures in the site's picture folder as
**Traditional paintings** in the **Pictures** menu. The folder is set in
``conf.py`` (this is the default):

.. code-block:: python

    rosary_images = "/_static/rosary-images"   # "" for no pictures

It holds 20 public-domain paintings (see
:doc:`traditional paintings </info/rosary_artworks>`).

A second folder, ``/_static/rosary-images_sg``, is offered as **Stained
glass windows**, for photographs of stained-glass windows. It works the same
way: pictures named ``joyful-1.jpg`` ... ``glorious-5.jpg``, an optional
``credits.txt`` and an optional ``full`` folder. Each folder becomes its own
entry in the **Pictures** menu; a folder that is missing or empty is left
out, and a mystery without a picture in the chosen folder uses its drawn
icon.

More folders can be listed in ``conf.py``, each with a short key and its
menu label (this replaces the two defaults):

.. code-block:: python

    rosary_image_sets = [
        ("photo", "Traditional paintings", "/_static/rosary-images"),
        ("sg", "Stained glass windows", "/_static/rosary-images_sg"),
        ("icons", "Eastern icons", "/_static/rosary-images_icons"),
    ]

A page can open on one with ``:icons: photo-sg`` (or ``photo-icons``). A ``full`` folder
inside it may hold the uncropped paintings with the same names; clicking a
picture then shows the whole painting with its caption.

To use other pictures:

Put the pictures in one folder, named by set and number:

.. code-block:: text

    joyful-1.png ... joyful-5.png
    luminous-1.png ... luminous-5.png
    sorrowful-1.jpg ...            (.png, .jpg, .jpeg, .webp, .gif or .svg)
    glorious-1.png ... glorious-5.png

then point the directive at the folder. A path starting with ``/`` is from
the ``docs`` folder; otherwise it is from the page's own folder.

.. code-block:: rst

    .. rosary::
        :images: /_static/rosary-images

Any picture that is missing uses the drawn icon. An optional ``credits.txt``
in the folder adds a caption under each mystery's title, one line per
picture:

.. code-block:: text

    joyful-1: Fra Angelico, The Annunciation (c. 1426), Museo del Prado, Madrid

:doc:`Traditional paintings </info/rosary_artworks>` lists a public-domain
painting for every mystery, with a ready-made ``credits.txt``. The pictures are copied into
the built site automatically. Square pictures work best: they are cropped to
fill the frame. Use only pictures you have the right to publish, such as your
own photos.


Site-wide starting choices
==========================

Each option above can be set for one page in its directive. The starting
choices for every rosary on the site are set in ``conf.py``; these are the
defaults:

.. code-block:: python

    rosary_default_icons = "photo-sg"        # classic, stained, gold, photo, photo-sg
    rosary_default_nav_icons = "classic"     # same, classic, stained, gold, photo, photo-sg
    rosary_default_layout = "phone"          # phone, compact, side, large
    rosary_default_verses = "current"        # all, current, none
    rosary_default_read = "step"             # step, both, scripture
    rosary_default_extra_prayers = "on"      # off, on, full
    rosary_default_fatima = True             # O my Jesus after each Glory Be

A picture style whose folder is missing falls back to ``classic``. A
reader's own choices from the **Options** menus are kept in their browser
and take over from these.

The opening and closing prayers are ``OPENING`` and ``CLOSING`` in
``rosary_data.py``: one entry per bead, with its label, name, intention and
prayers (keys of ``PRAYERS``).


Home Screen app
===============

So the site can be saved to a phone's Home Screen and open full screen, the
extension adds these to the ``<head>`` of every page after the build: the
``apple-mobile-web-app-capable`` and ``mobile-web-app-capable`` tags, an
``apple-touch-icon`` (``_static/rosary-touch-icon.png``) and a web app
manifest (``_static/rosary-manifest.json``). They are added to the built
pages themselves, so they work with any theme. In ``conf.py``:

.. code-block:: python

    rosary_web_app = True            # False to leave the tags out
    rosary_web_app_title = "Rosary"  # name under the icon (default: project)


Changing the references
=======================

#. Edit ``rosary_data.py``. Each mystery has a ``refs`` list of exactly ten
   ``(reference, caption)`` pairs; the module checks this when Sphinx loads it.
#. Download ``CPDV.csv`` from
   https://github.com/scrollmapper/bible_databases (``formats/csv``).
#. Rebuild the verse text. If a new passage is numbered differently in the
   Vulgate, add it to ``OVERRIDE`` in ``make_scripture.py`` first.

   .. code-block:: text

       cd docs\_ext\rosary
       python make_scripture.py CPDV.csv


Colours
=======

Each set has its own colour, set by CSS variables in ``rosary.css``:

.. code-block:: text

    .rosary-set--joyful    { --r-c: #2f6db5; ... }   /* blue */
    .rosary-set--luminous  { --r-c: #c48300; ... }   /* gold */
    .rosary-set--sorrowful { --r-c: #6d2e7a; ... }   /* purple */
    .rosary-set--glorious  { --r-c: #b0282c; ... }   /* red */

The icons take their colours from the same variables.
